This ZIP file contains all the necessary files and code used to create prototype devices for the ITSEM course. 
Included are the .ino files for various projects developed on the ESP32 platform:

hello_world_text
hello_world_sound
internet_radio
radio_pic
pong_game
snake_game
Along with these core files, the ZIP archive also includes any additional files required for the proper 
functionality of the codes. These resources encompass all the components used to implement and run the projects, 
ensuring that the prototypes work seamlessly.
